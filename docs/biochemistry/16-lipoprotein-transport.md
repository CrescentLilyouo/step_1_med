# 脂蛋白運輸：從腸道卸貨、肝臟配送到膽固醇回收

## 為何需要脂蛋白：先分血中貨物與包裝

TAG及cholesteryl ester難以直接溶在血漿中，因此以lipoprotein顆粒運送。顆粒核心偏疏水，裝TAG與cholesteryl ester；表面由phospholipid、free cholesterol與apolipoprotein形成可接觸水的介面。這是表面單層包覆疏水核心，不是細胞膜那種包住水相的典型脂雙層囊泡。

Free cholesterol仍有可接觸水相的羥基，常位於表面；酯化後羥基被接上脂肪酸，cholesteryl ester更疏水，較適合放核心。Apolipoprotein除了提供結構，還可當受體配體或酵素調節因子，並非只是在貨物外面貼一個名字。

| 血中形式 | 裝的是什麼 | 不要混淆 |
|---|---|---|
| Lipoprotein顆粒 | TAG、cholesterol、phospholipid等 | 有多種脂質，不是純膽固醇 |
| Albumin結合非酯化脂肪酸 | 脂肪組織釋放等來源的脂肪酸 | 不是chylomicron |
| Ketone bodies | 較水溶性的燃料 | 不靠LDL把每個酮體送出肝臟 |

LDL-C是LDL相關膽固醇量的檢驗概念，不等同LDL顆粒數，也不等同每顆粒裝載量完全固定。HDL-C也不是「所有HDL功能的總分」。先分清貨物、顆粒與功能，後面談疾病才不會只盯著一個數字。

## 大小、密度與成分：為何HDL密度最高

脂質相對蛋白質較低密度，脂質多而蛋白比例低的顆粒通常較大、密度較低。Chylomicron最大、TAG比例高；HDL較小、蛋白質比例高。不要把high density理解成「裝最多脂肪所以很重」。

| 類別 | 主要來源／轉變 | 相對富集貨物 | 核心辨認 |
|---|---|---|---|
| Chylomicron | 小腸 | 飲食TAG | ApoB-48 |
| VLDL | 肝臟 | 肝臟輸出的TAG | ApoB-100 |
| IDL | VLDL卸TAG後 | Remnant脂質 | ApoB-100、apoE |
| LDL | IDL進一步代謝 | Cholesterol／cholesteryl ester | ApoB-100 |
| HDL | 肝與腸等來源、血中重塑 | 蛋白比例高，參與膽固醇運輸 | ApoA-I |

一般密度順序由低到高為chylomicron、VLDL、IDL、LDL、HDL。表中「主要」不表示只含該成分：LDL也有磷脂與少量TAG，chylomicron也運送膽固醇。若選項說LDL主要是TAG，錯在比例；若說LDL完全不含TAG，同樣太絕對。

IDＬ不是肝臟額外製造的全新系列，而是VLDL在血中經過卸貨與重塑的中間狀態。脂蛋白分類反映顆粒組成與代謝階段，因此單一顆粒可隨代謝改變分類，不是一直保有同一名稱。

## Apo速查表要配合任務：48、100、C-II、E、A-I

先記固定在顆粒上的結構蛋白，再記可交換的調節蛋白。ApoB-48與apoB-100是相應顆粒的重要結構骨架，通常不在血中自由換來換去；apoC與apoE等則可在顆粒間交換。

| Apo | 主要任務 | 典型題目關鍵字 |
|---|---|---|
| ApoB-48 | 腸道chylomicron結構與組裝 | 外源性TAG、小腸 |
| ApoB-100 | VLDL→IDL→LDL結構；LDLR配體 | 肝臟來源、LDL受體辨認 |
| ApoC-II | 活化LPL | TAG卸貨 |
| ApoC-III | 抑制TAG清除相關步驟 | 與C-II方向不同 |
| ApoE | Remnant的肝臟攝取辨認 | Chylomicron remnant、IDL |
| ApoA-I | HDL重要結構與LCAT活化 | 膽固醇酯化、回收 |

ApoB-48與B-100來自同一APOB基因，腸道的RNA editing使訊息出現較早終止密碼，產較短蛋白；不是把血中apoB-100蛋白剪掉一半才得到B-48。B-48缺乏B-100的LDLR結合區域，因此chylomicron remnant主要靠apoE辨認，而非靠B-48模仿LDL。

記憶提示可用「B搭車架、C-II卸TAG、E收殘粒、A-I啟LCAT」，但每個提示都要配合位置。C-II是輔助LPL，不是自己當lipase；apoE是配體，不是把殘粒內脂質全數水解的酵素。

## 外源性路徑：腸道重新組裝後先進淋巴

長鏈飲食TAG先在腸腔消化，產物配合膽鹽微膠粒到達上皮附近，進入enterocyte後再酯化為TAG。Microsomal triglyceride transfer protein（MTP）協助apoB-48脂質化與chylomicron組裝，顆粒經分泌進入乳糜管與淋巴，之後到體循環。

微膠粒與chylomicron不是同一顆東西。微膠粒是在腸腔中幫助疏水消化產物接近吸收表面；chylomicron是細胞內重新包裝後，將脂質送往血液的顆粒。不能把整顆微膠粒畫成直接進淋巴，也不能說長鏈飲食TAG全部以原封不動形式穿過上皮。

| 階段 | 所在 | 主要功能 |
|---|---|---|
| 乳化與消化 | 腸腔 | 增加介面、lipase處理TAG |
| Mixed micelle | 腸腔 | 運送消化產物到吸收表面附近 |
| 再酯化與MTP組裝 | 腸上皮ER等 | 形成apoB-48顆粒 |
| Chylomicron分泌 | 淋巴→血液 | 配送外源性TAG |

短中鏈脂肪酸較水溶，可有不同吸收運送方式，不能把所有脂肪都套進相同淋巴路線。這章的外源性圖主要描述長鏈膳食脂質，遇到題目特別指出鏈長時，要回頭修正預設。

## LPL卸貨與殘粒回肝：把酵素、配體及目的地分開

新生chylomicron在血中與HDL等交換取得apoC-II、apoE。LPL在微血管內皮腔面發揮作用，水解顆粒內TAG，提供脂肪酸給肌肉、脂肪等組織。LPL由周邊細胞產生並受內皮定位機制調節，不能只因酵素在血管旁就說是自由漂浮於血漿的主要lipase。

TAG卸去後顆粒變小，部分apoC返回HDL，殘粒相對富含膽固醇並保留apoE；肝臟透過apoE相關辨認與受體介導攝取清除。這是「先配送一部分TAG，再將殘粒送回肝」的連續過程，不是所有飲食TAG一開始都以運到肝為唯一目的。

| 動作 | 主要分子 | 受影響時先想到 |
|---|---|---|
| TAG水解卸貨 | LPL、apoC-II | TAG-rich顆粒清除障礙 |
| 殘粒辨認 | ApoE及肝受體 | Remnant清除不足 |
| 細胞內脂滴動員 | ATGL、HSL等 | 自身儲備動員改變 |

LPL缺乏與apoC-II缺乏可有相似的TAG清除問題，但一個是執行酵素，一個是活化因子。胰lipase缺乏則先影響腸腔消化，不是同一個血中卸貨障礙。做題時只要先把位置畫出來，三種lipase就容易分開。

## 內源性路徑：VLDL先送TAG，再逐漸形成LDL

肝臟TAG可來自de novo脂肪酸合成、攝入的非酯化脂肪酸再酯化等。肝臟以apoB-100及MTP組裝VLDL，直接分泌到血液；它不是以apoB-48包成chylomicron。空腹時肝臟仍可能把部分脂肪酸再酯化並輸出VLDL，不能因正在氧化脂肪酸就宣稱完全沒有TAG合成。

VLDL經LPL卸去TAG後成IDL。IDL可被肝臟攝取，也可經進一步代謝、包括hepatic lipase相關重塑而形成LDL。不是所有IDL都必須先變成LDL，圖上要保留回肝分支。

| 轉變 | 主要變化 |
|---|---|
| VLDL→IDL | TAG減少，顆粒變小、相對膽固醇富集 |
| IDL→肝臟 | ApoE相關辨認清除 |
| IDL→LDL | 進一步失去TAG與可交換apo，保留apoB-100 |
| LDL→受體攝取 | 提供膽固醇，肝與周邊皆可攝取 |

同一顆粒的apoB-100在VLDL→IDL→LDL過程保留，並不是每變一次密度就重新合成一個apoB。LDL多由血中代謝形成，不能把「肝臟是脂蛋白主要來源」延伸成「肝臟直接分泌的主要顆粒就是LDL」。

這個序列也解釋為何TAG與LDL-C不一定同向等比例變化：顆粒產生、脂解、殘粒攝取及LDL清除是不同控制點，血中濃度是多個流量共同的結果。

## LDL受體攝取：血中很多，細胞仍可能覺得不夠

ApoB-100與LDL receptor（LDLR）結合後，顆粒經受體介導內吞。酸性endosome環境使配體與受體分離，受體通常可回收至細胞表面；脂蛋白送往lysosome，cholesteryl ester由lysosomal acid lipase水解，釋出free cholesterol。

細胞內膽固醇增加後，可抑制內生合成與LDLR表現，並促進酯化儲存。這裡必須區分「細胞內可利用的cholesterol」與「血液中LDL-C濃度」。LDLR功能不足時，血中LDL可能很高，細胞卻因攝取障礙而未收到相同程度的充足訊號。

| 步驟故障 | 可能影響 |
|---|---|
| 受體合成不足 | 細胞表面受體量低 |
| ER至表面運送異常 | 有蛋白也未必到正確位置 |
| 配體結合或內吞失常 | LDL不能有效攝取 |
| 受體回收不足 | 表面可用受體下降 |

LDLR不只存在肝細胞。肝臟對整體血中LDL清除很重要，但周邊組織也有受體。題目用「只在肝臟」常是將主要器官誇大成唯一器官。

## HDL回收：ABCA1、LCAT與SR-BI各接哪一棒

ApoA-I與早期HDL從細胞取得膽固醇及磷脂，ABCA1協助脂質外排到脂質較少的apoA-I等接受者；成熟HDL相關的外排還涉及ABCG1等。HDL不是一開始就裝滿cholesteryl ester才從肝腸分泌，成熟與載貨需要血中重塑。

LCAT（lecithin:cholesterol acyltransferase）在血漿中將PC的脂醯基轉給free cholesterol，形成cholesteryl ester及lysophosphatidylcholine；apoA-I可活化LCAT。酯化後cholesterol移向疏水核心，使HDL能繼續接受表面膽固醇。

SR-BI使肝臟等可選擇性攝取HDL的cholesteryl ester，不必每次都把整顆HDL連同所有蛋白全吞入。這和LDLR內吞整顆LDL的教學模型不同。

| 分子 | 主要任務 |
|---|---|
| ApoA-I | HDL結構、LCAT活化 |
| ABCA1 | 細胞脂質外排到早期接受者 |
| LCAT | 血漿膽固醇酯化 |
| SR-BI | 選擇性攝取HDL脂質 |
| ACAT／SOAT | 細胞內以acyl-CoA酯化cholesterol，非LCAT |

回收路徑把膽固醇從周邊重新分配到肝臟等位置，最後真正離開身體還需要膽汁／糞便相關排出。只把膽固醇從一顆粒移到另一顆粒，尚未等於完成排泄。

## CETP與顆粒交換：HDL-C數字不能代表全部功能

Cholesteryl ester transfer protein（CETP）可在HDL與apoB顆粒間交換cholesteryl ester及TAG；常見教學方向為HDL將CE交給VLDL/IDL/LDL等，換取TAG，CE再隨apoB顆粒被肝臟攝取。這是間接回收路線，不是CETP自己把膽固醇分解成CO₂。

LCAT負責酯化，CETP負責顆粒間轉移；ABCA1負責細胞向接受者外排，SR-BI負責選擇性脂質攝取。四個動作不同，不能用「都跟HDL有關」取代逐步解釋。

HDL-C較高在某些觀察性資料中與較低風險相關，但不能推成「只要把HDL-C升高，任何方式都一定保護血管」。顆粒功能、代謝背景與介入機制都會影響結果。本章以生化路徑建立辨認，不把單一數字當成臨床療效保證。

| 若只改變一項 | 仍需問的問題 |
|---|---|
| HDL帶的CE增加 | 是否順利交回肝臟或其他清除路徑？ |
| LDL-C增加 | 是產生多、轉換多，還是清除少？ |
| TAG增加 | 是chylomicron、VLDL或兩者滯留？ |
| 血中apoB增加 | 顆粒數及各顆粒成分如何變化？ |

以「流量」理解檢驗：水槽水位很高，可能是水進得太多，也可能排水口太小。脂蛋白濃度也是同樣邏輯；只見到高值不能立刻確定唯一酵素缺陷。

## 遺傳性異常：從產生、卸貨、清除三段定位

Familial chylomicronemia可涉及LPL或其功能所需因子等路徑缺陷。典型考題給LPL選項時，核心是血中TAG卸貨失常；不能只因家族性高血脂就一律選LDLR。Familial hypercholesterolemia（FH）則常見LDLR相關異常，也可涉及APOB、PCSK9或其他相關基因，不能把所有FH定義成只有一種突變。

| 異常 | 主要障礙 | 代謝線索 |
|---|---|---|
| LPL／apoC-II相關缺陷 | TAG-rich顆粒卸貨 | Chylomicron清除差、TAG高 |
| LDLR／apoB配體相關異常 | LDL攝取 | LDL-C高 |
| PCSK9 gain-of-function | 受體降解增加 | 可造成LDLR可用量下降 |
| ApoE相關殘粒清除障礙 | Remnant回收 | IDL／remnant堆積；表現受背景影響 |
| MTP缺陷 | ApoB顆粒組裝 | 可影響腸與肝來源顆粒 |
| ABCA1缺陷 | 細胞膽固醇外排 | Tangier disease相關、HDL很低 |

MTP缺陷會影響apoB脂質化與分泌，與LPL缺陷的「顆粒已進血但卸不掉貨」不同。若題幹出現脂肪吸收異常、低apoB顆粒與脂溶性維生素問題，要先想組裝出口，而非把所有異常解釋成血中脂解失敗。

上述是機轉定位，不是僅靠單一血脂值即可做出基因診斷。尤其apoE相關疾病的表現受代謝因素影響，不能把某一基因型與所有人必然發病畫上等號。

## 餐後與空腹：同時看脂肪組織、肌肉與肝臟

餐後腸道chylomicron帶來飲食TAG，脂肪組織較支持攝取與再酯化；insulin一方面支持脂肪組織LPL相關儲存方向，另一方面抑制細胞內脂滴動員。這不是同一個lipase同時被開又被關，而是位置不同的酵素完成不同工作。

空腹時腸道新輸出的飲食TAG減少，脂肪組織釋放非酯化脂肪酸，由albumin帶給肌肉與肝臟。肝臟可氧化、產酮，也可將部分脂肪酸再酯化成TAG後以VLDL輸出。不能用「空腹」直接排除VLDL，也不能把肝臟輸出顆粒改名為chylomicron。

| 狀態 | 主要燃料來源線索 | 儲存／動員的核心 |
|---|---|---|
| 餐後 | 飲食TAG與葡萄糖 | 腸道配送、組織儲存 |
| 較短空腹 | 肝醣＋脂肪組織脂肪酸 | 供糖與燃料動員並行 |
| 較長空腹 | 糖新生＋脂肪酸／酮體 | 跨器官節省葡萄糖 |

脂肪肝可從流量失衡理解：脂肪酸輸入及合成超過氧化與輸出能力，TAG便可能累積。這不表示只有de novo synthesis增加才會脂肪肝；輸入過多、氧化受限或VLDL組裝輸出不足，也可改變平衡。

## 三條路徑一起畫：用錯誤選項做定位練習

第一條外源性：小腸→apoB-48 chylomicron→LPL卸TAG→apoE殘粒→肝。第二條內源性：肝→apoB-100 VLDL→IDL，分支回肝或成LDL→LDLR。第三條回收：周邊細胞→apoA-I／HDL→LCAT酯化→SR-BI直接回收，或CETP間接接上apoB顆粒路線。

遇到題目先圈四件事：來源是小腸還是肝？貨物主要是TAG還是cholesterol？要問水解、酯化、轉移還是內吞？顆粒現在是原始、remnant還是成熟LDL？四個答案能把大多數apo與酵素放回正確位置。

例如「肝臟把TAG包成chylomicron」錯在來源與骨架apo；「血中VLDL由HSL卸貨」錯在酵素位置；「LDL receptor只在肝」錯在把主要改成唯一；「新生HDL已富含大量CE」忽略成熟過程。若舊題對這些敘述採多答案或一律給分，仍以官方採計呈現，正文另說明標準機轉。

這一章完成的標準不是能背五種脂蛋白名稱，而是把同一份脂質從來源、卸貨到清除畫完，並說出每一步哪個蛋白負責、缺陷後哪一種顆粒會累積。下一章再把顆粒中的膽固醇拉出來，追它如何合成、感測及真正排出身體。
