# 第 03 章　蛋白質結構、摺疊與功能失常

本章以 Harper’s Illustrated Biochemistry 第 31 版第 5 章為主軸，結合第 4 章的分析方法。目標是從胺基酸序列一路推理到三維構造、實驗結果與疾病，而不是只背四級結構的定義。

## 學習地圖：同一條鏈如何變成可工作的分子

第 2 章學的是材料：側鏈的大小、電荷與反應性。本章問的是，這些材料如何被安排成可結合氧、催化反應或支撐組織的形狀。某個殘基能否作用，除了「它是什麼」，還取決於它在三維空間中靠近誰、是否接觸水、能不能移動。

一條肽鏈不是細胞先做好僵硬骨架再裝上側鏈；主鏈與側鏈彼此限制，共同決定可採取的構形。序列相距很遠的殘基，摺疊後可能共同構成活性中心；序列相鄰的殘基則未必朝同一方向。這是為什麼突變可以在遠離活性中心的位置改變功能。

讀題時先辨認層次：題目問序列、局部氫鍵模式、整條鏈的摺疊，還是不同鏈的組裝？接著辨認作用力：是在問主鏈氫鍵、側鏈疏水效應，或共價雙硫鍵？最後才判斷改變 pH、溫度或加入還原劑會造成何種結果。

## 四個結構層次：區分鏈內與鏈間

|層次|核心問題|例子|易錯處|
|---|---|---|---|
|一級 primary|殘基沿主鏈的排列順序|β-globin 第 6 位 Glu 變 Val|不能只說胺基酸種類與數量；順序也重要|
|二級 secondary|局部主鏈採取什麼重複構形|α helix、β sheet、β turn|主要看主鏈幾何與氫鍵，不是側鏈序列清單|
|三級 tertiary|單條多肽鏈如何整體摺疊|myoglobin 的 globin fold|不要求有多條鏈，單體也有三級結構|
|四級 quaternary|多條多肽鏈如何排列與互動|HbA 的 α₂β₂|一條鏈有四個 domain 不等於四級結構|

有些定義將雙硫鍵的共價連接位置納入完整的一級結構描述；國考問「穩定三級構造的共價作用力」時仍通常選雙硫鍵。前者在描述完整共價連接資訊，後者在問這個鍵對摺疊的作用，並不矛盾。

結構層次也不是四個彼此獨立的抽屜。一級序列改變可能影響二級構形、三級摺疊或四級組裝；選擇性剪接可改變序列，不能說只影響 RNA 而與蛋白質無關。蛋白質也可能在不同寡聚狀態間轉換，不一定永遠固定同一種四級結構。

## 主鏈幾何與 Ramachandran plot

肽鍵 C–N 因醯胺共振帶部分雙鍵性，旋轉受限；主要構形自由度來自 N–Cα 的 φ 與 Cα–C 的 ψ。Ramachandran plot 將這兩個角度作為座標，顯示哪些組合在立體上較可行。空白區不是「細胞不喜歡這個顏色」，而是某些原子會靠得太近，產生高能量的碰撞。

Gly 的側鏈只有 H，容許的角度較廣；Pro 的側鏈接回主鏈氮，使 φ 的範圍更受限。因此同一張一般殘基的允許區域圖不能毫無調整地套在 Gly、Pro 上。常見右手 α helix 與伸展 β strand 位於不同角度區域，反映不同的主鏈排列。

多數肽鍵為 trans；X–Pro 的 cis 比例相對較高，cis/trans 的轉換可能成為摺疊速度的限制步驟。Peptidyl-prolyl isomerase 可以加速此異構化，但不改變最終平衡的熱力學原則。

不需要先背所有角度數字才理解摺疊。先掌握「肽單元近似平面、相鄰單鍵可旋轉但有障礙、特定角度重複形成規則二級構造」，就能串起大部分結構題。

## α 螺旋：氫鍵、方向與螺旋偶極

一般蛋白質常見的是右手 α helix。每圈約 3.6 個殘基，沿軸每個殘基上升約 1.5 Å，每圈螺距約 5.4 Å。典型氫鍵由第 i 位主鏈 C=O 接受第 i+4 位主鏈 N–H 提供的氫；側鏈向外伸出，並不是藏在螺旋中央。

「α helix 靠氫鍵穩定」需要說清楚是哪裡的氫鍵：規則的主鏈 C=O 與 N–H 配對是核心。側鏈也會影響穩定性，但不是把每個 R 基團彼此氫鍵連成螺旋。許多微弱互動累積才形成穩定構造，單一氫鍵並非無法被水競爭。

主鏈肽鍵具有偶極，規則排列使整段螺旋的 N 端偏部分正電、C 端偏部分負電。這與自由 N 端/C 端的化學電荷是不同概念；即使螺旋位於整條鏈中間，仍可有螺旋偶極。酸性側鏈靠近螺旋 N 端、鹼性側鏈靠近 C 端，有時可提供有利的靜電作用，但仍須看局部結構。

**算例：** 若一段理想 α 螺旋約 20 個殘基，長度量級約 20×1.5 = 30 Å，可跨越膜疏水區的量級。精確端點距離與使用 n 或 n−1 個間隔有關；題目通常要你理解為何跨膜 α 螺旋常需約二十個左右的殘基，而非硬套每條膜都一樣厚。

## β 摺板、轉角與規則結構的中斷

β strand 為較伸展的主鏈，相鄰 strand 之間以主鏈氫鍵形成 β sheet。相鄰股的 N→C 方向相同叫平行，相反叫反平行；相鄰股可以來自同一條鏈不同區段，也可以來自不同鏈。因此看到 β sheet 不代表一定是四級結構。

β strand 的側鏈交替朝摺板兩側。若序列每隔一個殘基呈疏水性，可能形成一面疏水、一面親水的兩親性 β 結構。α helix 則需考慮每圈約 3.6 個殘基，不會以完全相同的交替規律形成同一面。

|比較|α helix|β sheet|
|---|---|---|
|主鏈形狀|螺旋|延伸股並排|
|常見氫鍵配對|同段鏈 i 與 i+4|相鄰 β 股間|
|側鏈方向|向外環繞|交替朝兩面|
|序列遠近|典型為局部相鄰區段|配對股可在序列上相距很遠|
|方向分類|常見右手螺旋|平行或反平行|

反平行 β sheet 的氫鍵幾何通常較接近直線；平行配對較傾斜，是教材比較兩者局部氫鍵強度的原因。但整個蛋白質穩定性還受側鏈、溶劑與其他互動影響，不宜推出所有反平行蛋白質一定比平行蛋白質耐熱。

β turn 常使鏈急轉，典型涉及四個殘基，可見 i 與 i+3 的主鏈氫鍵；Gly、Pro 常出現在轉角，但理由不同。Gly 小而靈活，Pro 的環限制角度且可固定某些轉彎。內部 Pro 少了常見主鏈 N–H 供體，常中斷規則 α 螺旋或 β 結構，卻不是完全不能形成任何氫鍵。

## Motif、domain 與 subunit：三個常混淆名詞

Motif（基序）是反覆出現的局部結構安排或序列模式，例如 helix-turn-helix、β-α-β。Domain（結構域）是較大的緊密單位，常能相對獨立摺疊，並負責特定功能。Subunit（次單元）則是寡聚蛋白質中的一條多肽鏈。三個名詞關心的尺度與問題不同。

一條蛋白質可以有多個 domain，每個 domain 裡又有多個 motif；多條這樣的鏈再組成複合體。若一個受體具有細胞外配體結合域、跨膜區與細胞內酵素域，不能把三個區域自動算成三個 subunit。

序列 motif 不一定等於整個三維結構 motif，也不必然證明功能。看到一段疏水序列只能提出跨膜或疏水核心的假設，需結合長度、位置及其他證據。Hydropathy plot 是把連續序列的疏水性作窗口平均，用來尋找可能跨膜的片段，不直接測出分子量、四級結構或含水量。

## 摺疊的驅動力：把蛋白質與水一起算

水溶性球狀蛋白通常將較多非極性側鏈埋入內部。分散暴露的疏水表面會影響周圍水的排列；疏水表面聚在一起時，一部分受限制的水被釋放，能有利於整個系統的自由能。這是疏水效應，不能將它描述成新形成的一條特殊共價「疏水鍵」。

摺疊讓肽鏈本身的構形選擇減少，鏈的構形熵通常下降；但不能因此斷言總熵一定下降或摺疊不自發。要比較蛋白質加溶劑的整體 ΔG = ΔH − TΔS。氫鍵、鹽橋、凡德瓦爾接觸、溶劑重排及構形熵一起決定結果。

|互動|化學本質|讀題時的要點|
|---|---|---|
|疏水效應|溶劑相關的自由能效應|常是球狀蛋白形成內部核心的重要因素|
|氫鍵|非共價|主鏈與側鏈皆可參與，要辨認位置|
|離子作用／鹽橋|帶電基團間作用|受 pH、距離與環境影響|
|凡德瓦爾作用|短距離弱作用|良好堆積可累積穩定作用，太近則排斥|
|雙硫鍵|兩個 Cys 氧化形成共價 S–S|對還原劑敏感，不能列為非共價作用|

蛋白質的穩定性往往來自許多互動的差額，不是「鍵越多永遠越穩」。把極性基團埋入內部卻沒有合適配對可能付出能量代價；膜蛋白面向脂質的表面可富疏水殘基，也不能硬套所有疏水基團一律藏內部。

## 能量地景、Anfinsen 實驗與分子伴護子

蛋白質不可能把所有構形逐一試完才找到正確答案。局部結構與有利接觸會限制後續搜尋，摺疊可經多條路徑與中間態到達穩定構形。能量地景常以漏斗示意：往低自由能方向前進，但可能被局部低谷困住或形成錯誤聚集。圖是概念模型，不表示每條蛋白質都有相同的單一路徑。

RNase A 的經典復性實驗顯示：以尿素破壞摺疊、以還原條件處理雙硫鍵後，若在適當順序與環境移除處理，蛋白質可恢復天然結構與活性。若仍在變性環境就讓雙硫鍵隨機重建，容易形成錯配而活性低；允許雙硫鍵重新交換後，可走向較有利的配對。核心結論是序列包含摺疊所需的重要資訊，不是所有蛋白質離開細胞都必定自動完整復性。

Chaperone 會暫時結合暴露的疏水區或提供受保護的環境，降低未摺疊鏈彼此聚集的機會。Hsp70、Hsp60/chaperonin 等常利用 ATP 結合與水解驅動工作週期；也有不直接用 ATP 的伴護系統，因此應說「許多重要伴護系統需要 ATP」，不是所有都一樣。

伴護子不會把自己的胺基酸接進受質，通常也不成為成熟蛋白的永久次單元。它提供有利於正確摺疊的條件，並非替任意錯誤序列指定正常形狀。Protein disulfide isomerase 協助雙硫鍵交換；peptidyl-prolyl isomerase 加速 Pro 肽鍵的順反異構化，兩者解決不同的摺疊瓶頸。

## 變性與復性：用處理條件判斷哪一層被破壞

變性是原有天然構形與功能受破壞，不一定切斷主鏈肽鍵。加熱、極端 pH、尿素或界面活性劑都可能使蛋白質展開，但主要作用機制不完全一樣。若殘基序列未被切斷，仍可能失去活性，因為活性中心需要三維排列。

|處理|主要影響|不能直接推出|
|---|---|---|
|加熱|改變非共價作用與構形分布，可能聚集|所有肽鍵都已水解|
|極端 pH|改變質子化、鹽橋與局部結合|每次活性下降都是完全變性|
|尿素／guanidinium|干擾維持天然構形的溶劑與非共價互動|一定直接切斷雙硫鍵|
|SDS|變性並賦予大量負電|已還原全部雙硫鍵|
|DTT／β-mercaptoethanol|還原雙硫鍵|一般主鏈肽鍵也被剪斷|
|蛋白酶|水解特定肽鍵|只是改變三級結構而保留完整序列|

移除變性劑後能否復性，取決於是否已聚集、形成錯配共價鍵、被化學修飾或失去必要輔因子。煮熟蛋白不能回到原狀，是理解不可逆聚集的例子，但不能把它推廣成所有變性都不可逆。

## 錯誤摺疊、amyloid 與 prion

錯誤摺疊可能造成失去原本功能，也可能獲得聚集或毒性作用。細胞會透過伴護、降解與運輸品質管制處理問題；若需求超過處理能力，就可能累積不正常蛋白質。蛋白質品質控制不是單純把所有不完美構形立刻清除，也包含嘗試重新摺疊。

Amyloid 常具有跨 β（cross-β）排列：β 股與纖維長軸大致垂直，形成高度有序的纖維架構。不同疾病的前驅蛋白可不同，卻收斂成類似聚集構造。因此不能把 amyloid 當成某一種特定胺基酸序列，也不能說所有 β sheet 都是病態；大量正常蛋白本來就含 β 結構。

Prion 的重要概念是錯誤構形可促進同種正常蛋白轉成類似異常構形。正常 PrP 與疾病相關構形的序列可能相同，而二級與高階構形不同；病態形式相對富 β 結構，且較易聚集、對部分蛋白水解較有抗性。「具有傳播能力的蛋白構形」不等於一般病毒，不能把其感染性歸因於自身攜帶核酸基因體。

Aβ、tau、α-synuclein 等可用來理解不同蛋白病的概念，但本章不把所有神經退化疾病都歸為同一機制。國考先掌握序列與構形可分離、β 富集與聚集相關，以及正常 β 結構並非病態即可。

## 膠原蛋白：三股螺旋不是 α 螺旋

Collagen 的主題是抗拉強度。每條鏈富含 Gly、Pro 及修飾後的 hydroxyproline，常有 Gly–X–Y 重複，其中每第三個位置的 Gly 很重要，因三股螺旋中心空間狹小，只容許極小側鏈。X 常見 Pro，Y 常見 hydroxyproline，但不是每一個 X/Y 都固定相同。

單條 collagen 鏈採取不同於典型 α helix 的延伸螺旋構形，三條鏈纏成右手三股超螺旋。相鄰鏈間氫鍵與後續交聯共同支持結構。不要看到「螺旋」就回答 i→i+4 的 α 螺旋氫鍵；兩者幾何不同。

|常見型別|典型分布|記憶關聯|
|---|---|---|
|I|骨、肌腱、皮膚等|抗拉支架；成骨不全症常涉及 I 型|
|II|軟骨、玻璃體等|軟骨與眼部結構|
|III|網狀纖維、血管及多種軟組織|血管型 Ehlers–Danlos 與 III 型相關|
|IV|基底膜網狀結構|網狀，不是典型長纖維束|

型別表是常見考點，不是所有組織只含一種 collagen。臨床疾病也可能涉及合成酵素、修飾或組裝，而非只有主鏈基因突變。

## 膠原蛋白成熟：細胞內修飾與細胞外交聯

先在粗糙內質網合成前驅鏈，移除訊號胜肽，並對特定 Pro/Lys 進行羥化。這些 hydroxylase 需要 Fe²⁺、O₂、α-ketoglutarate 等參與，維生素 C 有助維持催化所需的鐵還原狀態。部分 hydroxylysine 再接醣，三條鏈經對齊後組成 procollagen 三股螺旋。

Procollagen 分泌後，在細胞外切除端部 propeptide，再組裝成纖維；lysyl oxidase 透過氧化脫胺生成可交聯的醛基，這一步需要銅，與維生素 C 參與的羥化不是同一步。交聯增加纖維抗拉能力。

|階段|位置／條件|常見失誤|
|---|---|---|
|Pro/Lys 羥化|內質網，與維生素 C 有關|誤背成維生素 K 或細胞外交聯|
|部分 hydroxylysine 醣基化|細胞內|把所有 Lys 都當作醣基化位置|
|三股螺旋組裝|分泌前|把單條 α chain 誤當典型 α helix|
|端部切除與纖維組裝|分泌後的細胞外|忘記前驅物與成熟纖維不同|
|lysyl oxidase 交聯|細胞外，銅相關|與 hydroxylase／維生素 C 混淆|

壞血病可從羥化不足理解結締組織脆弱、出血與傷口癒合不良。成骨不全症常涉及 I 型 collagen 的量或結構異常；某些 Ehlers–Danlos 類型涉及 collagen 或其加工，不能把所有亞型都歸因於同一酵素缺陷。讀病例先找骨脆、皮膚延展、關節鬆弛或血管脆弱等線索，再對照故障層級。

## 纖維蛋白比較：collagen、elastin 與 keratin

Elastin 的核心功能是伸展後回彈，富含可產生疏水互動的區域，並由特定 Lys 衍生的交聯維持網絡。Desmosine／isodesmosine 交聯是重要辨認點，其形成也與 lysyl oxidase 有關。Fibrillin 微纖維提供彈性纖維組裝支架；Marfan syndrome 典型與 fibrillin-1 相關，不是把它當作 collagen I 突變。

α-Keratin 常見於毛髮、指甲等，α 螺旋鏈形成 coiled-coil；不同程度的雙硫鍵交聯影響材料性質。Collagen 抗拉、elastin 回彈、keratin 保護支撐，是三個不同的結構—功能例子。

|蛋白／支架|結構關鍵|功能線索|
|---|---|---|
|Collagen|Gly–X–Y、三股螺旋與交聯|抗拉、骨與肌腱等支架|
|Elastin|彈性網絡、desmosine 類交聯|動脈與肺等組織回彈|
|Fibrillin|微纖維支架|彈性纖維組裝與相關訊號環境|
|α-Keratin|coiled-coil、Cys 交聯|毛髮、角化組織|

## 實驗判讀：大小、電荷、純化與結構證據

SDS-PAGE 將蛋白質變性並賦予近似一致的負電荷／質量比，遷移主要反映大小。加入還原劑後還能拆開雙硫鍵連接的鏈。Native PAGE 則保留較多天然互動，遷移受大小、形狀與電荷共同影響，不能單靠一條帶直接精確判分子量。

**算例：** 某蛋白在合適的天然分子量分析下約 100 kDa，非還原 SDS-PAGE 約 50 kDa，還原 SDS-PAGE 只有 25 kDa 一種帶。可提出四個 25 kDa 鏈組裝，其中兩兩由雙硫鍵相連、兩個二聚體間主要非共價結合的模型。但單一 25 kDa 帶不能證明四條鏈序列相同；不同鏈也可能大小相同，且天然大小測量受形狀等條件影響。

|方法|主要依據|容易顛倒的方向|
|---|---|---|
|Size-exclusion chromatography|水動力大小|大分子較難進孔洞，通常先流出|
|Ion-exchange chromatography|淨電荷|陰離子交換樹脂帶正電，吸附負電分子|
|Affinity chromatography|特異結合|如 His-tag 與固定金屬配位，不是單純按大小|
|Isoelectric focusing|pH 梯度中的 pI|蛋白集中於淨電荷約零的位置|
|SDS-PAGE|變性後主要依大小|較小多肽通常跑得較遠|

X-ray crystallography 由繞射資料推得電子密度與模型；NMR 可研究溶液中的結構與動態；cryo-EM 可由多個投影重建結構，通常不需形成蛋白晶體。任何方法都有解析度與樣品限制，模型也不是完全靜止的真實細胞。計算預測可提出結構假說，但不能單憑一張預測圖證明活性、親和力或特定配體一定結合。

## 閉卷整合：從改變到結果

遇到「加入還原劑」先想到 S–S，而非所有非共價作用；遇到「高溫」先想到構形與聚集，不先假設肽鏈全部斷裂。遇到「序列遠端突變影響催化」，先考慮三級結構、動態或異位性傳遞，而不是認為離活性中心遠就一定無效。

用三條因果鏈檢查理解：Gly 被較大殘基取代 → collagen 中央堆積受干擾 → 抗拉結構異常；疏水表面暴露 → 蛋白彼此不當接觸 → 聚集與功能失常；酵素序列未變但 pH 改變 → 質子化與互動改變 → 可能活性下降甚至變性。

本章最後應能分清四組：二級主鏈氫鍵與三級整體核心、domain 與 subunit、變性與水解、正常 β sheet 與病態 amyloid。下一章將以血紅素展示正常蛋白如何利用構形變化調節功能。
