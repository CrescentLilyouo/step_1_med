## cell-physiology
### 先找回三個工具，再開始細胞生理
本章反覆使用三種推理。第一是**守恆**：粒子與水從哪裡來、移到哪裡、總量有沒有變。第二是**驅動力乘通透能力**：有梯度但沒有通道不一定有流動，通道開啟但已達平衡也不一定有淨電流。第三是**事件順序**：電位變化、通道活化、鈣上升與收縮先後相接，不能倒過來。

先依序讀膜運輸、滲透、膜電位，再進動作電位與突觸，最後看肌肉。若忘記物理符號，先記 Vm＝細胞內電位減細胞外電位，負值代表內側較負；Eion 是只針對某離子算的平衡點，gion 是通道提供的導通性。後面每個公式都要先講出這三者各在說什麼。

| 本章路徑 | 讀完後應能自行解釋 |
| --- | --- |
| 膜運輸 → 滲透 | 物質能否跨膜如何改變水分布 |
| 平衡電位 → 動作電位 | 通道數、驅動力與失活如何改變興奮性 |
| 突觸 → 三種肌肉 | 電訊號在哪一步轉成鈣訊號，又在哪一步變成力 |

### 完整示範：由平衡電位推電流
**教學自編例，非歷屆原題。** 37°C，胞內 K⁺ 140、胞外 4 mmol/L，Vm＝−70 mV。對一價陽離子 EK≈61.5 log₁₀(4/140)≈−95 mV。先算平衡點，再算驅動力 Vm−EK≈＋25 mV；若 gK＝10 nS，IK≈＋250 pA。正的傳統電流表示正電外移，K⁺ 外流會把膜電位帶向 EK。

若只把 gK 加倍，固定 Vm 的電壓箝制條件下電流加倍；若沒有箝制，Vm 會移動，驅動力隨之下降，不能永遠說電流維持兩倍。這一步是在練習辨認題目固定了哪個變數。
### 引導練習：只改胞外鉀
胞外 K⁺ 由 4 升至 8 mmol/L，胞內仍為 140，且先把 Vm 固定 −70 mV。請依序填出新的 EK、驅動力、K⁺ 流向。提示：濃度加倍使一價陽離子的平衡電位增加約 18.5 mV。
<details><summary>完成三步後核對</summary><p>EK 約 −76 mV，驅動力約＋6 mV，仍為外向 K⁺ 電流但幅度減小。若放開電壓箝制，實際 Vm 依全部離子導通性決定。常見錯誤是把「外鉀變高」立即翻成「鉀一定向內」。先比較 Vm 與新的 EK。</p></details>
### 閉卷變式：把問題換成興奮性
持續高外鉀造成去極化時，為什麼肌力可能先受刺激、後來卻減弱？請用「平衡電位、Na⁺ 通道可用性、動作電位」三個詞串起來，再核對。
<details><summary>寫出機轉後看解答與補讀方向</summary><p>EK 變得較不負可使膜去極化，輕度時較接近閾值；持續或嚴重去極化則使 Na⁺ 通道失活，可用通道不足，動作電位與傳導受影響，肌力可減弱。若卡在電流方向回讀平衡電位；若卡在先興奮後無力回讀動作電位的失活與恢復。</p></details>
## neurophysiology
### 先畫訊號路徑，再讀每一個感覺與運動系統
神經章的共同句型是**刺激 → 轉導 → 傳入 → 中樞處理 → 輸出**。每個箭頭都可能換訊號形式，受器電位是漸變訊號，軸突動作電位以頻率編碼，突觸又可依受體產生不同方向反應。若這些名詞很模糊，先回讀細胞章動作電位與突觸，再往下定位。

本章先保留原有目錄順序。讀每個系統時先確認正常路徑，接著追問「如果在這裡中斷，哪些功能消失、哪些留下」。路徑定位要標交叉點，回饋題要區分直接刺激與反射輸出，高階功能題要列保留與受損的任務。

| 讀題線索 | 先畫什麼 |
| --- | --- |
| 感覺側別不一致 | 各種感覺自己的交叉位置 |
| 同一刺激有相反效應 | 突觸後受體與反轉電位 |
| 刺激器官後 HR 反向改變 | 直接效應與壓力反射兩條路 |
| 能動卻不協調 | 命令、選擇與校正的不同角色 |

### 完整示範：左胸髓病灶如何定位
**教學自編例，非歷屆原題。** 左側 T10 脊髓半側受損。先畫左腿的振動覺經左後柱往延腦，因在胸髓尚未交叉，故病灶下方同側振動、本體覺可能受損。再畫右腿痛溫傳入，進髓後於附近節段交叉到左側上行，故左胸髓病灶可造成對側痛溫覺缺損，常從病灶下方幾節開始。最後看已在延腦交叉的皮質脊髓束，下方同側可出現上位運動神經元型障礙，但急性期反射可能先受脊髓休克影響。

這題的答案來自三條路徑各自交叉位置，不能用一條「腦是對側、脊髓是同側」概括全部感覺。
### 引導練習：只移動病灶位置
若病灶改在右側內囊，請先判斷該處的體感與主要運動路徑是否已完成相關交叉，再推主要身體症狀側別。提示：要將感覺上行與運動下行分別追到病灶。
<details><summary>畫完路徑後核對</summary><p>右內囊主要對應左側身體感覺與運動。感覺的交叉已在較下方完成；下行皮質脊髓纖維則在更下方延腦交叉到左側。兩者在同一病灶呈現相同對側症狀，但交叉相對於訊號行進的先後不同。臉部與個別束路仍需依病灶範圍細分。</p></details>
### 閉卷變式：相同側別不代表同一系統
左側小腦病變造成左手測距不準，是否應推左手振動覺一定消失？請寫出「訊號傳入存在」與「利用訊號校正動作」的差別。
<details><summary>完成推理後核對</summary><p>不能。小腦協調障礙可在初級感覺保留時出現，問題在時序與誤差校正。若把所有同側症狀都歸同一條束路，回讀運動控制；若分不出感覺喪失與協調失準，回讀體感受器編碼，再逐項列理學功能。</p></details>
## cardiovascular
### 先把壓力、流量、容積與時間分開
本章使用四種量。壓力是推動與負荷，流量是每單位時間送出多少，容積是某時點裝了多少，時間線則決定瓣膜與電機械事件的順序。**高壓不必然高流量，EF 正常不必然 CO 正常，心率快也不必然補償成功。** 每道題先辨自己要回答哪一種量。

連續閱讀可先依目錄建立血流與電生理，再讀收縮與每搏量。若 PV 環難以理解，先開心動週期一節依四次瓣膜事件走完，再回來看環。血壓調節之後才接微循環、器官差異與站立失血。這個順序讓曲線能對回真實事件。

| 機轉層次 | 本章反覆使用的關係 |
| --- | --- |
| 血管 | Q＝ΔP/R；順應性＝ΔV/ΔP |
| 心室 | SV＝EDV−ESV；EF＝SV/EDV |
| 整體循環 | CO＝HR×SV；MAP−RAP≈CO×TPR |
| 穩態 | 左右心平均輸出相等，CO 與 VR 相等 |

### 完整示範：心率增加但輸出下降
**教學自編例，非歷屆原題。** 原 HR 70/min、EDV 120 mL、ESV 50 mL，則 SV 70 mL、EF 58%、CO 4.9 L/min。失血後 HR 100/min、EDV 75 mL、ESV 40 mL，則 SV 35 mL、EF 約 47%、CO 3.5 L/min。交感使心率增加、收縮狀態可能改變，但前負荷大幅下降仍可讓整體輸出減少。

若要再推 MAP，必須知道 TPR；若要推供氧，還要知道 Hb 與 SaO₂。不要把這題算出 CO 後，對所有其他變數都自動下結論。
### 引導練習：只增加後負荷的一搏
原 EDV 120、ESV 50 mL，保持起始 EDV 與收縮力不變，突然增加射血負荷，該搏 ESV 成為 65 mL。請算 SV、EF，並說明 PV 環變寬或變窄。
<details><summary>算完後核對</summary><p>SV＝55 mL，EF≈45.8%，環寬減少。若你把後負荷上升誤當作收縮力上升，會錯推 ESV 下降。這裡描述第一搏；後續 EDV 與反射可再改變。</p></details>
### 閉卷變式：站起來的前後兩段
由平躺突然站立，請依序寫出最初的 VR、EDV、SV、動脈壓變化，再寫壓力受器放電、交感與 HR 的方向。不要把反射後變化寫成起始原因。
<details><summary>完成因果鏈後核對</summary><p>下肢靜脈儲血增加使 VR、EDV、SV 與動脈壓短暫下降；壓力受器放電下降，交感增加、迷走減少，使 HR、收縮力與血管張力上升以補償。若第一段錯回讀回流與心輸出量；若第二段錯回讀血壓反射。實際恢復程度取決於補償能力。</p></details>
## respiratory
### 從空氣抵達肺泡，一路追到組織收到氧
先讀肺容積與通氣，再看肺如何張開、氣體如何跨膜、血流如何配對，最後才看 Hb 運輸與呼吸控制。每一步都有自己的限制，**吸進很多氣、PaO₂ 正常與組織供氧足夠是三件不同的事**。如果記憶斷在公式，先把公式左邊用中文說出來，再追右邊每個因子。

前置觀念包括細胞章的擴散與壓差，以及心血管的 CO。PaO₂ 是壓力，SaO₂ 是比例，CaO₂ 是含量，DO₂ 才是每分鐘供氧。V̇E 與 V̇A 也要分開。正文每遇到數字，先寫 mmHg、mL/dL 或 L/min，避免只憑數字大小判斷。

| 階段 | 先問的問題 |
| --- | --- |
| 肺泡通氣 | 每一口扣掉死腔後剩多少？ |
| 氣體交換 | PAO₂ 與 PaO₂ 差多少？通氣有配到血流嗎？ |
| 血中攜帶 | Hb 有多少、飽和幾成？ |
| 組織輸送 | 每分鐘有多少血送到組織？ |

### 完整示範：正常 PaO₂ 仍供氧不足
**教學自編例，非歷屆原題。** Hb＝15 g/dL、SaO₂＝0.98、PaO₂＝100 mmHg、CO＝5 L/min。CaO₂＝1.34×15×0.98＋0.003×100≈20 mL/dL。5 L/min＝50 dL/min，所以 DO₂≈1000 mL O₂/min。

若 Hb 降到 7.5、其餘固定，CaO₂≈10.15 mL/dL，DO₂≈508 mL/min，約剩一半。PaO₂ 正常反映溶解氧張力，無法補回少掉的 Hb 容量。這是公式與概念必須一起使用的原因。
### 引導練習：增加心輸出量能補多少
承上 Hb＝7.5 的情境，若 CO 增至 7 L/min，其餘不變，請先換成 dL/min，再估 DO₂。提示：含氧量沿用 10.15 mL/dL。
<details><summary>換算後核對</summary><p>7 L/min＝70 dL/min，DO₂≈710.5 mL/min，部分補償但仍低於原本約 1000。若算成 71，通常漏掉 L 到 dL 的十倍換算。此為控制其他變數的教學估算，不代表臨床一定能達到該 CO。</p></details>
### 閉卷變式：呼吸快卻換氣變差
死腔固定 150 mL，呼吸由 500 mL×12/min 變為 250 mL×24/min。請計算兩種 V̇A，再在 CO₂ 產生率固定下推 PaCO₂ 的方向。
<details><summary>自行算完後核對</summary><p>V̇A 由 4.2 變為 2.4 L/min，PaCO₂ 會上升；若原本 40，理想穩態比例估約 40×4.2/2.4＝70 mmHg。若以同為 6 L/min 判完全相同，回讀死腔；若方向錯，回讀 CO₂ 產生率與肺泡通氣的反比關係。</p></details>
## renal
### 一條守恆貫穿整章，先建立小管地圖
腎臟題看似公式多，其實可先用**尿排出＝濾過−回收＋分泌**串起來。先知道血送來多少、濾出多少，再沿近端、Henle 環、遠端與集合管讀內容物如何改變。最後把血液與尿液的差別接回全身水、電解質與酸鹼。

前置觀念是膜運輸與滲透。先確認濃度乘流率才是每分鐘的量，清除率則是排出率除血漿濃度。酸鹼又要接呼吸的 PaCO₂。讀到不懂的縮寫時先回到這些單位，能避免同時記大量無關公式。

| 不能混用的兩個量 | 區分方式 |
| --- | --- |
| 尿濃度與排出率 | 後者還要乘尿流率 |
| 血鈉與全身鈉量 | 前者受水相對比例影響 |
| 尿 pH 與淨排酸 | 前者是游離 H⁺，後者算緩衝酸總排出 |
| HCO₃⁻ 回收與新生 | 回收避免流失；淨排酸可對應新增鹼 |

### 完整示範：尿酸不代表排酸足夠
**教學自編例，非歷屆原題。** 一天尿 NH₄⁺ 40、可滴定酸 25、HCO₃⁻ 5 mEq，NAE＝40＋25−5＝60 mEq/day。每個數字已是一天總量，不需再乘尿量。尿 pH 即使很低，也不能替代這三項，因大量 H⁺ 是跟緩衝物一起排出。

若要判是否足以維持全身酸平衡，還需知道每日固定酸生成與其他酸鹼得失。NAE 的單一數值沒有脫離情境的「永遠正常」意義。
### 引導練習：只減少銨排出
承上 NH₄⁺ 降至 15 mEq/day，其他維持，請算 NAE 差多少。若固定酸負荷仍為 60 mEq/day，忽略其他收支，每天淨保留多少酸？
<details><summary>完成兩個差額後核對</summary><p>NAE＝15＋25−5＝35，較原來少 25 mEq/day；酸生成 60、淨排 35，淨保留 25。尿 pH 即使仍低也不能排除這種不足。若算成 45，多半把排出的 HCO₃⁻ 錯加成排酸。</p></details>
### 閉卷變式：把尿資料接回血液
某人高鉀、正常 AG 代謝性酸中毒且尿 pH＜5.5。有人說「尿已經很酸，所以腎臟排酸一定正常」。請指出推論缺少哪個量，並解釋高鉀可能影響的環節。
<details><summary>寫出缺漏後核對</summary><p>缺尿 NH₄⁺ 等總排酸資訊。高鉀可抑制腎臟銨生成，讓總排酸不足，即使尿能酸化。若卡在量與濃度回讀清除率；若卡在銨與新生 HCO₃⁻ 回讀腎排酸；若無法確認原發異常再回讀酸鹼代償。</p></details>
## gastrointestinal
### 用一餐的旅程串起神經、分泌、消化與吸收
食物進入口腔後，要依序被潤滑、推進、混合、分解與吸收。消化道不是單純直管，每段會根據內容物調整下一段工作。先讀神經與激素控制、運動，再讀唾液、胃、胰、膽，最後看吸收與腹瀉，能把同一餐串成連續故事。

前置觀念是極性上皮與膜運輸。頂膜面向腸腔，基底外側面向間質與血液；消化不足與吸收不足也要分開。遇到腹瀉先問未吸收溶質、分泌增加、回收下降各占多少，再接失水、低鉀與 HCO₃⁻ 流失。

| 食物到達位置 | 下一步正常反應 |
| --- | --- |
| 口腔與胃 | 分泌、容受、混合並控制排空 |
| 十二指腸酸 | secretin 促鹼液，中和後利於酵素作用 |
| 小腸脂肪與蛋白 | CCK 參與酵素、膽囊與排空調節 |
| 刷狀緣 | 分解成可運輸形式，再經特定路徑吸收 |

### 完整示範：同樣腹瀉，先找留下的粒子
**教學自編例，非歷屆原題。** 採常用估計糞便滲透濃度 290 mOsm/kg，糞便 Na⁺ 30、K⁺ 40 mmol/L，滲透間隙≈290−2×(30＋40)＝150。較大的未測粒子貢獻支持滲透性成分，例如未吸收醣類；仍需結合禁食反應、病史與其他資料。

式中的 2 是用來把主要陽離子及其伴隨陰離子計入，不是因為鈉鉀都是二價。用這個理由記公式，才不容易漏乘或重複乘。
### 引導練習：只改糞便電解質
同樣估計 290，改為 Na⁺ 90、K⁺ 40 mmol/L，請算間隙，並說明可測電解質占比的變化。
<details><summary>算完後核對</summary><p>間隙≈290−260＝30，較小，表示主要滲透粒子較能由電解質解釋，支持分泌性成分。單一間隙不是獨立確診，也不直接辨認是哪個毒素、受體或疾病。</p></details>
### 閉卷變式：吸收與分泌可同時存在
某刺激提高腸上皮 CFTR 相關 Cl⁻ 分泌，但 Na⁺–葡萄糖共同運輸保留。請畫出分泌與吸收各一條路，並解釋為何不能說「腸道已完全不吸水」。
<details><summary>畫完兩條路後核對</summary><p>Cl⁻ 分泌可帶動 Na⁺ 與水進腔，SGLT 仍可回收 Na⁺ 與葡萄糖並支持水吸收，最後糞水取決於兩方向淨差。若卡在蛋白位置回讀細胞膜上皮運輸；若卡在淨差回讀腸道水鹽；若漏掉酸鹼後果再回讀腎章 HCO₃⁻ 收支。</p></details>
## endocrine
### 先讀回饋，再讓每個腺體填入同一張地圖
內分泌最重要的是把**來源、血中形式、受體、效果與回饋**連起來。先讀激素訊號與腦下垂體，再用同一方法理解甲狀腺、腎上腺、胰島、鈣磷與生殖。遇到某激素升高，先問是分泌多、清除少、結合蛋白多，還是目標不反應而代償上升。

前置觀念包括細胞內訊號、負回饋及濃度與總量。類固醇合成要畫酵素路線，月經與妊娠要畫時間線。不要在未指定時期下記一個永久不變的回饋方向，尤其排卵前 estrogen 與 LH 的關係。

| 讀題順序 | 需要回答 |
| --- | --- |
| 末端效應 | 游離激素與目標功能高或低？ |
| 上游回應 | 應被抑制還是應增加？實測是否適當？ |
| 位置 | 原發腺體、中樞、受體或代謝環節？ |
| 時間與形式 | 急性或穩態？總量或游離量？ |

### 完整示範：正常範圍也可能不適當
**教學自編例，非歷屆原題。** 游離 T4 明顯低，TSH 卻在實驗室正常範圍。先問正常負回饋應怎樣反應：低末端激素應解除抑制，使 TSH 增加。現在沒有適當上升，因此需考慮中樞軸問題，不能因 TSH 打在參考區間就判整個軸正常。實際判讀仍需病程、用藥與其他檢驗排除干擾。

比較另一種情境：游離 T4 低且 TSH 明顯高，則上游已有適當刺激，更支持原發甲狀腺功能不足。兩者都低 T4，差別在回饋是否成立。
### 引導練習：只改結合蛋白
TBG 增加，達新穩態後總 T4 高、游離 T4 與 TSH 正常。請說明「總量高」為何不等於「作用過強」，並指出最關鍵的回饋證據。
<details><summary>寫出三者關係後核對</summary><p>更多結合位置提高血中總 T4，游離激素可透過調節回到適當水平。游離 T4 與 TSH 的正常配對支持軸的回饋穩態，不能僅用總量高判功能亢進。若卡住回讀血中運輸與受體作用。</p></details>
### 閉卷變式：外源激素讓內源功能下降
長期外源 glucocorticoid 使血中有足夠作用，為何內源 ACTH 與皮質醇生成可能下降？再類比外源 testosterone 對 LH、FSH 與精子生成的影響。
<details><summary>完成兩條回饋鏈後核對</summary><p>外源 glucocorticoid 提供負回饋，抑制上游 CRH、ACTH，使內源皮質醇生成下降。外源 testosterone 也可壓低 LH、FSH，削弱睪丸局部環境與精子生成。血中有激素作用不代表自身腺體仍正常工作。若只記下游濃度，回讀訊號與回饋，再分別核對腎上腺與男性生殖軸。</p></details>
