## 科目

- 解剖學、組織學、胚胎學
- 生理學、生物化學、藥理學

- 免疫學、公共衛生學

## 歷屆試題與考古快寫（2026-10-13）

- 檢查考選部查詢平台民國 81–115 年；可取得的醫師第一階段試題涵蓋 96–115 年、每年兩場，共 80 份原卷、8,000 題。
- 完整保存 215 份官方 PDF：80 份試題、62 份標準答案、73 份更正答案。早期部分場次只有更正答案；未提供的答案檔不補造。
- 原始檔位於 `exams/<民國年度>/<場次>/medicine-<卷別>-<Q|S|M>.pdf`；完整來源、下載網址及 SHA-256 見 `question-bank/sources.json`。清單及各科題數見 `question-bank/manifest.json`。
- 11 科均新增「考古快寫」：可依年度、場次篩選，每回無放回隨機五題，交卷後顯示分數、可接受的官方答案與原卷／官方來源。未作答不給分；「一律給分」與「有作答才給分」分開處理，支援更正所接受的複選組合。
- 以更正答案（M）優先、標準答案（S）次之；歷史試題按當年官方答案計分。科目分類為本站依原題與當年出題區段的學習整理，並非考選部逐題官方標籤；跨科題保留原卷出處。
- 早年科目編排與現行不同。106 年第二次起原題使用現行分組，但部分查詢標籤仍保留舊名稱；分類以 PDF 本身為準。
- 所有題目由自備 PDF.js 在瀏覽器直接呈現原卷裁切區域；跨頁題保留所有區段，因此原圖、圖中標記、特殊符號及表格不經轉寫。文字轉錄僅供輔助，遇舊字型應以原題圖像為準。
- 原題預覽失敗時提供原卷頁碼連結與重試按鈕。各科資料按需載入，PDF.js 與 worker 均放在儲存庫內，無須外部 CDN。
- 既有五部影片筆記、重繪圖、章節導覽、搜尋與已讀記錄均保留。

題庫檢查與重建：

```sh
python scripts/build_bank.py
node scripts/test_quiz.cjs
```

重建需 PyMuPDF；測試需 Node.js。`question-bank/audit.json` 記錄逐卷題數、採用的答案版本與更正項目。PDF.js 3.11.174 依 Apache-2.0 授權提供（見 `PDFJS-LICENSE.txt`）；停用其動態求值。因本環境沒有可用的 Browser control，未進行互動瀏覽器實測；已檢查全部題目／答案的完整性、抽題與計分規則，並抽樣檢視跨頁圖題裁切。

官方資料來源：考選部考畢試題查詢平臺 <https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx>。

## 陽明平台線上詳解（2026-10-14）

交卷後，每題直接嵌入原作者公開 Google Drive 的原書閱讀器，不需下載或匯入。保留資源金鑰，提供新分頁閱讀及作者勘誤入口。7,546 題附 PDF 頁碼、254 題提供本卷詳解、200 題明示尚無公開詳解。Google Drive 閱讀器不能保證自動跳頁，故清楚提示使用者輸入對照頁碼；未宣稱逐題裁切或自動跳到該頁。原書由原作者的主機提供，不重新上傳整套詳解。

同時只保留一個展開的閱讀器，收合或離開頁面即釋放 iframe。程式不讀取本機檔案、不建立 IndexedDB，也不載入 ZIP 解碼器。舊版個人匯入檔案若存在，不會被讀取或修改；可由瀏覽器網站儲存設定清除。

驗證：全部 49 份原書網址／resourcekey 格式及 8,000 題對照檢查；測試展開、收合、換題、無詳解與載入失敗處理。未進行瀏覽器互動實測。
